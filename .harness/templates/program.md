本文件定义本次变更的约束与评估规则。任务拆分仍以 `tasks.md` 为准。

**`## 评估规则` 是 Evaluator 判定通过/失败的唯一权威**，由 `verification.json`
的 `rule` 字段引用。写在这里但没有步骤引用的规则会被 lint 报错；有步骤引用但
尚未通过的规则会挡住归档就绪度。

按风险等级选择结构，**不要为无关小节填写「不适用」占位**——整节都是占位内容
会被 lint 报告为应按等级移除：

| 等级 | 必需小节 |
| --- | --- |
| `low` | 风险等级、必须验证、不验证及理由、可观测性与回滚、评估规则 |
| `medium` | 追加 约束 |
| `high` / `critical` | 再追加 停止条件 |

`必须验证` 与 `不验证及理由` 是一对，**不能只留否定的一半**：只写「不跑什么」而
不写「跑什么」，读者无法判断覆盖面。`可观测性与回滚` 在 `low` 档可以很短，但不能
没有——出问题时去哪看、怎么退回，与风险等级无关。
